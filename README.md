## 📌 Assignment Overview

This project satisfies the **Week 1 – Web Development Assignment 1: Create Your Portfolio Webpage** from the Web Development Internship Practice roadmap.

### 🎯 Key Focus:
- **Structure**: Semantic HTML5 markup (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **Design & Layout**: Pure CSS styling with Flexbox, CSS Grid, custom properties, modern dark/light mode aesthetics, and fluid responsiveness.
- **Content**: Required sections — **About**, **Education**, **Skills**, and **Contact** with a developer profile photo.

---

## ✨ Features

- 🎨 **Modern Premium Design**: Glassmorphic header, smooth dark/light theme switching, custom gradients, typography from Google Fonts (`Outfit` & `Plus Jakarta Sans`).
- 👤 **About Section**: Professional developer bio, quick highlights, profile illustration, and social media handles.
- 🎓 **Education Section**: Interactive chronological timeline highlighting academic degrees, institutions, duration, and key coursework tags.
- 🛠️ **Skills Section**: Categorized proficiency cards with animated progress indicators and modern tech stack badges.
- 📬 **Contact Section**: Detailed contact info along with an interactive form featuring real-time client-side field validation and feedback messaging.
- 📱 **Fully Responsive**: Mobile-first architecture with custom hamburger menu drawer for smartphones and tablets.
- ♿ **SEO & Accessibility**: Structured headings (`h1`-`h4`), ARIA labels, semantic landmark tags, and high color contrast.

## 🏷️ Semantic HTML Tags Implemented

- `<header>`: Site branding and top-level navigation.
- `<nav>`: Main menu navigation links.
- `<main>`: Primary page content container.
- `<section>`: Dedicated sections (`#hero`, `#about`, `#education`, `#skills`, `#contact`).
- `<article>`: Self-contained timeline entries in the Education section.
- `<footer>`: Copyright, assignment metadata, quick links, and back-to-top control.
